任务简报

你刚刚入职 XX 信息安全测评中心，被任命为项目经理，独立带队完成「」的等保测评任务。

整个项目按课程四大阶段拆成四大闯关关卡：测前准备、现场核查实施、报告交付、进阶与风险评估。每关通过后，下一关才会解锁；定级环节（S / A 与取高者）是重中之重，将引导你一步步完成判定。

  • 四大关卡：依次对应课程四大阶段——测前准备 → 现场核查实施 → 报告交付 → 进阶与风险评估。
  • 串行解锁：完成当前大关卡所有步骤后，下一关才会解锁；未解锁的关卡呈灰色 🔒 状态。
  • 每步流程：阅读【情景】→ 完成【任务】→ 输入答案 → 提交；系统按关键词与关键数字评分（1~3星），并给出标准答案与知识点讲解。
  • 定级攻坚：测前准备关卡包含 S / A 评定与「取高者」专题，答错会获得针对性纠错。
  • 工具包：右下角按钮可随时打开五级概览、S / A 矩阵、六要素口诀等参考资料。
  • 通关结算：每完成一关即可查看本关交付报告；所有大关卡通关后综合评级。

① 五级安全等级概览

等级名称典型系统测评频次
一级用户自主保护级乡镇级/中小企业无需强制测评
二级系统审计保护级县级政务、高校、一般企业每两年至少一次
三级安全标记保护级地市级政务、金融机构每年至少一次
四级结构化保护级国家重要领域核心系统强制保护
五级访问验证保护级国防/军事极端重要系统专控保护

② S / A 判定矩阵

等级S 业务信息安全（数据出事）A 系统服务安全（服务中断）
二级损害公民/法人权益严重损害公民权益或损害社会秩序
三级严重损害社会秩序/公共利益严重损害社会秩序或损害国家安全
四级特别严重损害社会秩序/公共利益特别严重损害社会秩序或严重损害国家安全

S 看数据 · A 看服务 · 最终等级 = max(S, A)

③ 定级口诀与流程

「先定对象 · 再评 S/A · 取高者 · 专家审 · 报备案」

依据 GB/T 22240《定级指南》。二级及以上须向公安机关备案，取得《备案证明》后才能开展等级测评。业务或 S/A 变化时须重新定级。

④ 方案六要素口诀

「一项依据两范围，三对对象四指标，五定方法六日程」

六要素：项目概述 / 测评范围 / 测评对象 / 测评指标 / 测评方法 / 日程与人员。完整方案共9章：封面、目录、项目概述、测评依据、测评范围、测评对象、测评指标、测评方法、日程安排、人员分工、风险控制与附件。

⑤ 高频丢分点

  • 混淆 S 与 A —— S 看数据出事，A 看服务中断；
  • 忘记「取高者」—— 最终等级 = max(S, A)；
  • 测评依据只写「等保标准」，不写编号（须写 GB/T 22239-2019 等）；
  • 对象清单用「若干」「一些」—— 必须具体到型号与台数；
  • 认为一级系统也要强制测评（一级无需强制测评）；
  • 定级对象写成某台服务器（应是承载独立业务的信息系统）。
